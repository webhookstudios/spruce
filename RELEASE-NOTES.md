# Spruce 1.2.0

Spruce keeps its name. It now has the Sedge look shared by every webhookstudios app: one set of colors, fonts and icons, in light and dark mode.

- New icon, colors and fonts. Window titles and headings use the Sedge serif.
- A main menu with an About window.
- Everything works exactly as before. Your settings and presets carry over.

Install:

```bash
sudo apt install ./spruce_1.2.0_all.deb
```
